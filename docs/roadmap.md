# Atlas Intelligence Platform — Future Roadmap

The core portfolio target is implemented. Future work should be incremental rather than a rewrite.

1. Add richer pagination discovery for cursor/infinite-scroll sites.
2. Add organization/team membership if Atlas becomes multi-tenant.
3. Add an audited browser sandbox/proxy for stricter SSRF isolation.
4. Add more deterministic site fixtures and browser integration tests in CI.
5. Add optional AI-assisted schema mapping behind an explicit per-job setting.
6. Add retention policies and raw-response storage only if a real use case requires them.
